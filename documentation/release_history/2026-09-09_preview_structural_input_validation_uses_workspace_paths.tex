   \begin{preview}
      Fixed a false \texttt{Missing LaTeX input} diagnostic in Preview. The
      Preview render policy previously checked references beginning with
      \texttt{/} directly against the operating-system root, even though Mind
      Mirror defines those references as rooted at \texttt{search.default\_path}
      first. Structural \texttt{\textbackslash input} and
      \texttt{\textbackslash include} validation now delegates to the same
      workspace-aware resolver used by recursive Preview expansion, so
      references such as \texttt{/nd\_language\_ai\_project/...} are validated
      consistently.
   \end{preview}
