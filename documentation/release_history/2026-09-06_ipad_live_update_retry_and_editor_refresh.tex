   \section{Observed failure}
   The durable Ubuntu open request was newer than the last
   \texttt{graphic\_update\_event.json} entry, showing that the current graphic
   could be opened on the iPad while later canvas saves were not reaching the
   Ubuntu-side update event path.

   \section{Fix}
   \begin{itemize}
      \item The final iPad save is no longer discarded after a small fixed retry
      count. The newest state remains the only in-flight retry and is retried
      until Ubuntu acknowledges it, or until document close/reset terminates
      the session.
      \item The retry interval is short enough to recover quickly after a
      transient reverse-TCP disconnect while still coalescing newer canvas
      states.
      \item Every newly accepted Ubuntu graphic update event explicitly rebuilds
      Source graphic preview layout and refreshes Visual graphic resources, so
      editor-side image caches cannot remain stale after the PNG was replaced.
      \item Existing live update-rate settings, Undo/Redo, rename remapping,
      and bounded close behavior remain unchanged.
   \end{itemize}
