      \section{Fixes}
      \begin{itemize}
         \item The reverse Ubuntu-to-iPad connector now keeps discovering and reconnecting the iPad for the complete bridge lifetime whenever no live TCP client exists. Reconnection is no longer gated by a pending image or TikZ open request, so a dropped or half-open connection can recover without manually stopping and restarting the bridge.
         \item A normal left-click on a Navigator folder no longer writes image data from the system clipboard into that folder. Clipboard images are now written only through explicit paste actions such as \texttt{Ctrl+V} or \textbf{Paste Clipboard Image Here}, preventing accidental \texttt{img\_*} files while browsing the Navigator.
      \end{itemize}
