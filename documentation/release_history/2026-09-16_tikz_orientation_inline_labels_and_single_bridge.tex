      \section*{TikZ canvas orientation, inline labels, and bridge singleton fix}

      The fast Ubuntu TikZ preview now reads the source-backed
      \texttt{nd\_mind\_mirror\_canvas} metadata instead of rendering into a
      hard-coded landscape image. A diagram edited on the default
      \(760\times980\) iPad canvas is therefore previewed with the same portrait
      page aspect ratio on Ubuntu.

      Double-tap label editing is again performed directly inside a node or at
      the connector label position. The temporary floating label bar above the
      canvas was removed. Label drafts still commit on Return or when editing
      loses focus, while the workspace continues to ignore keyboard safe-area
      changes so the drawing canvas is not re-laid out by the compact iPad input
      assistant.

      The ND Graphic launcher now enforces one bridge instance for the current
      workspace. Starting it replaces stale same-user bridge processes for that
      workspace, refuses busy canonical ports instead of silently choosing
      fallback ports, and keeps a process lock for the lifetime of the bridge.
      Direct module startup likewise refuses fallback ports. This prevents old
      and new bridges from repeatedly stealing the reverse iPad TCP connection,
      which previously produced repeated reconnects, \texttt{IncompleteReadError},
      \texttt{Unknown message: update\_tikz}, delayed saves, and unnecessary CPU
      load.

      The bridge version was advanced to \texttt{0.31.49}.
   \end{preview}
