      \section{Bug fix}

      Preview now uses the same three canonical path modes as workspace
      navigation and refactoring: file-relative references, references rooted
      at \texttt{search.default\_path} with a leading slash, and true operating
      system absolute paths.

      The renderer owns workspace-aware input and graphic dependency resolvers
      from construction time.  Before restored editor tabs can request their
      first Preview, the enhanced window injects the configured
      \texttt{search.default\_path} through the renderer's public API.

      This removes the startup interval in which restored files could be
      rendered with the generic recursive resolver and incorrectly report a
      valid default-rooted input such as
      \texttt{/nd\_research\_publication/...} as missing.

      Regression coverage now verifies all three path modes and verifies that
      session restore configures the workspace root before the base restore
      can reopen tabs and trigger Preview.
   \end{preview}
