\title{Replace Native Tab Overflow Popup}
\date{2026-09-22}
\author{Mohammad Rahmani}

\begin{document}
   \maketitle

   \begin{preview}
      \section{Cause}
      The desktop-native QTabBar overflow popup keeps platform selection state
      independently of pointer hover. Repeated attempts to restyle that
      transient internal widget could therefore leave stale backgrounds or
      selected white text.

      \section{Fix}
      Native QTabBar overflow controls are disabled. Each Pinned/Open row now
      owns one explicit triangle button and a small Qt.Popup containing one
      dedicated row widget per tab. Each row owns its hover directly:
      \texttt{enterEvent} sets a light-purple background and black text, while
      \texttt{leaveEvent} restores a transparent/default background and keeps
      text black. There is no selected, current, active-action, delegate or
      platform hover state involved.
   \end{preview}
