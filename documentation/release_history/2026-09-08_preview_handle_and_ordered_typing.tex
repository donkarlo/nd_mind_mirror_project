   \section{Bug fixes}

   \begin{itemize}
      \item The LaTeX diagnostics splitter handle now has a dark visible idle
      state, with distinct hover and pressed states, so the resize affordance
      remains visible before the pointer grabs it.
      \item Windowed large LaTeX Source editors no longer replace their
      materialized QTextDocument while a character-input burst is active.
      Re-window operations requested near a Source window edge are deferred
      until the typing burst becomes idle, then resumed once.
      \item Canonical source-buffer edits still happen immediately for every
      QTextDocument character edit; only the disruptive visible-window reload
      is delayed.
   \end{itemize}

   This protects ordered key input during fast typing such as
   \verb|include| while preserving the existing bounded large-document Source
   architecture.
