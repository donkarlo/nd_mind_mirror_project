   \begin{preview}
      \section{Bug}
      Styling the native item view with hover/selected pseudo-states allowed the
      active Qt style to report several rows in the same visual state, so more
      than one overflow option could become purple.

      \section{Fix}
      The native overflow list now uses a dedicated item delegate. The
      controller tracks the exact model index emitted by the view's entered
      signal. The delegate removes native hover, selection, and focus paint
      flags, paints light purple only behind that one tracked row, and delegates
      the original text/icon rendering unchanged. Leaving the popup clears only
      this transient hover index; it does not alter selection or current index.
   \end{preview}
