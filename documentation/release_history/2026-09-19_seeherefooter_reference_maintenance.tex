\section{Bug fix}
Workspace path maintenance now recognizes \texttt{\textbackslash seeherefooter\{...\}}
as a local file reference. Renaming or moving the referenced target preserves the
command and rewrites only its path argument. Deleting the referenced target removes
the complete \texttt{\textbackslash seeherefooter} command through the same
reference-maintenance pipeline used by other LaTeX references.
