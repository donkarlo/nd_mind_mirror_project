      \section{Fixed behavior}

      Preview diagnostics no longer promote warning-only LaTeX and bibliography
      output to a red compilation error.

      \begin{itemize}
         \item natbib citation warnings remain warnings.
         \item BibTeX \verb|Warning--| messages remain warnings.
         \item rerunfilecheck warnings remain warnings.
         \item Real LaTeX failures such as undefined control sequences, missing
         files, and fatal compiler errors remain errors.
         \item Warning severity is owned by a dedicated classifier and the
         diagnostic builder extends the existing tree builder instead of
         embedding ad-hoc message checks in the UI.
      \end{itemize}
   \end{preview}
