      \section{Fix}
      The native iPad graphic bridge now tears down the accepted Ubuntu connection and listener before application suspension, preserves the user's request to keep listening, and rebuilds the listener after the application becomes active again. Listener recovery is delayed briefly after wake so the previous Network.framework listener can release port 8768 and Wi-Fi can become usable before rebinding. Failed or waiting listener states schedule an automatic retry instead of leaving the app permanently disconnected until a manual restart.
