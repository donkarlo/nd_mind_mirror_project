   \begin{preview}
      \section{Bug}
      Even after removing the explicit QToolButton arrow type, attaching a
      QMenu through \texttt{setMenu()} still allowed the active Qt style to
      draw faint automatic menu-indicator arrows next to the intended tab-list
      arrow.

      \section{Fix}
      The tab-list control no longer attaches the QMenu to QToolButton at all.
      It renders one literal downward-arrow glyph and opens the owned QMenu
      directly from the button's clicked signal.  Therefore Qt has no menu
      subcontrol from which it can generate additional gray arrows.
   \end{preview}
