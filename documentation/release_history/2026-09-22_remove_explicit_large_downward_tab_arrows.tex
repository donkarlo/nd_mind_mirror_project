      \section{Bug fix}
      The custom tab-overflow implementation added an explicit large downward
      triangle button to each Pinned/Open row.

      \section{Fix}
      The explicit overflow button and its popup are no longer created by the
      Pinned/Open row controller. QTabBar native scroll buttons remain disabled,
      so this controller adds no downward-triangle widget.
