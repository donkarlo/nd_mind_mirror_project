      \section*{Exact selection bookmark range regression}
      Selection-only bookmarks could expand from a short mouse-selected text
      range to the complete logical paragraph after an editor operation rewrote
      the containing paragraph. The range tracker treated the containing
      replacement itself as the new bookmark range.

      The bookmark collection now first re-anchors the original bookmarked text
      inside any containing replacement. Source highlighting independently
      resolves the exact stored bookmark text near its canonical range and never
      paints an approximate paragraph when the exact text cannot be resolved.

      Regression tests cover the observed \texttt{die normal Schlafstunde}
      selection, unchanged whole-paragraph rewrites, changed containing
      paragraphs, and virtualized Source window offsets.
   \end{preview}
