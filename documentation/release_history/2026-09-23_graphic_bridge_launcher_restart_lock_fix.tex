      \section{Fix}
      The standalone graphic bridge launcher now stops an existing bridge for the same workspace before acquiring the lifetime singleton lock. Previously the old bridge process inherited that lock, so a Control Panel restart exited immediately with ``already running'' before it could reach the existing-process replacement logic. The launcher now performs the intended replacement first and then acquires the singleton lock with a bounded wait.
