\section*{Desktop File Search Responsiveness and Path Resolution --- 2026-10-10}
The Files \& Folders tab now retains its completed index across repeated Double-Shift
openings and reuses unchanged displayed results. Literal and hierarchical matches
are processed before the more expensive fuzzy fallback, keeping normal filename
lookups responsive across large workspaces. Background matching remains cancellable.

Pasting an existing full filesystem path or a workspace-root-relative path now
shows a directly openable file or revealable folder, including matches outside
an intentionally narrowed search scope. An explicit \texttt{Refresh index} button
resynchronizes the cached index with externally created, renamed, or deleted files.
The cooperative search worker now shares the canonical ranking implementation,
including ordered \texttt{parent > child} hierarchy handling.
