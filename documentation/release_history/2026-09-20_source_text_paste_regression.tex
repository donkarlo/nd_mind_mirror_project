   \begin{preview}
      \section{Bug}
      Plain-text paste in Source failed from both Ctrl+V and the standard
      right-click Paste action. The runtime log showed that the clipboard image
      path raised an AttributeError before QTextEdit could receive its normal
      text MIME fallback.

      \section{Fix}
      The clipboard owner again provides the image extraction operation expected
      by the existing image allocator, and ordinary text MIME deterministically
      returns no image. Local-image insertion now handles one or many original
      file references before the pixel-image fallback, so the fix does not
      recreate duplicate image assets for a single dragged image.

      \section{Regression coverage}
      Tests exercise plain-text MIME directly and verify that a single local
      image remains an original-file reference.
   \end{preview}
