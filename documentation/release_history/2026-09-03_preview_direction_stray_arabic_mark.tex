   \section{Bug fix}
   \begin{itemize}
      \item Fixed a live Preview regression where a single Arabic combining mark, such as Unicode U+0651 SHADDA, could incorrectly classify an otherwise English LaTeX document as Persian and make the generated PDF right-to-left.
      \item Persian Preview support now relies on the existing \texttt{LatexTextDirectionResolver} and requires at least one strong Arabic-script alphabetic character. Combining marks, punctuation, joiners, and other non-letter code points no longer enable Persian as the Babel main language.
      \item Existing Persian documents remain supported because real Persian/Arabic letters still enable the same Preview-only Babel and font setup.
      \item Added regression tests for the exact English-plus-SHADDA case and for genuine Persian text.
      \item The user's source document is not rewritten as part of this fix.
   \end{itemize}
