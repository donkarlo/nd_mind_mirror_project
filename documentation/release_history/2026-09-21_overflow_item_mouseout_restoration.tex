   \begin{preview}
      \section{Bug}
      A popup row could keep the transient hover background after the pointer
      moved to another row because hover was driven by entered-state changes
      rather than an explicit per-row mouseout restoration.

      \section{Fix}
      The overflow popup viewport now resolves the row under every mouse move
      with \texttt{indexAt}. When the hovered row changes, the old row is
      immediately invalidated and repainted with the normal palette background,
      while only the new row receives the light-purple background. Leaving the
      viewport clears the hover index and repaints the popup.
   \end{preview}
