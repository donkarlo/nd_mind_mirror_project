   \begin{preview}
      File Navigator new-document creation no longer reuses internal LaTeX Preview wrappers. Article and Beamer documents now have independent document templates that omit the active \texttt{preview} package, \texttt{PreviewBorder}, preview environments, and the internal \texttt{ND\_MIND\_MIRROR\_CONTENT} marker.

      The Preview wrapper templates remain unchanged so tight standalone and TikZ rendering continues to use the page-boundary behavior required by the Preview subsystem.

      Settings migration now changes only the two accidentally shared shipped paths. User-defined custom document-template paths are preserved. The current autonomous-control document was also cleaned of the active Preview package directives that caused \texttt{No pages of output} after its preview environment was removed.
   \end{preview}
