      \section*{Bug fix}
      LaTeX Preview diagnostics no longer discard the source-context lines printed
      immediately after errors such as \texttt{Undefined control sequence}.

      \begin{itemize}
         \item Added a dedicated compiler diagnostic extractor.
         \item Strong compiler errors are emitted before citation/package warnings so
         the diagnostic summary identifies the actual compilation failure.
         \item The failing LaTeX context, including lines such as
         \texttt{l.254 \textbackslash brokencommand}, is preserved.
         \item Added focused tests for undefined-control-sequence, warning-only, and
         empty-output cases.
      \end{itemize}
   \end{preview}
