      \section{Fixes}
      \begin{itemize}
         \item Replaced the platform-dependent tab overflow popup with a deterministic Mind Mirror tab list so long paths no longer produce inconsistent two-line menu rows.
         \item Navigator Copy/Cut now publishes a real file-URL clipboard payload, replacing stale image data. Local file URLs are treated as file-copy data rather than clipboard pixels, so copying files no longer causes an unrelated image to be pasted when a destination folder is clicked.
         \item Source-mode image drops now resolve every local image URL in one MIME payload and insert one figure reference per original file without creating duplicate \texttt{img\_0}/\texttt{img\_1} assets.
      \end{itemize}
