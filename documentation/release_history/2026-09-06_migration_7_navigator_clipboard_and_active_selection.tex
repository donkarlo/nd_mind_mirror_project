   \section{Changes}
   \begin{itemize}
      \item Navigator now uses extended row selection so Ctrl-click cherry-picking and Shift-click range selection work for files and folders.
      \item Ctrl+C, Ctrl+X, and Ctrl+V operate on all selected top-level Navigator paths. Copy and Cut are also available directly in the right-click menu.
      \item Right-clicking an item already inside a multi-selection preserves the complete selection. Right-clicking an unselected item makes that item the single context target.
      \item Paste collisions suggest suffix-aware names such as \texttt{name\_0}, \texttt{name\_1}, and \texttt{file\_0.tex} while allowing the suggested name to be edited before the operation continues.
      \item Cut/Paste is routed through the existing background workspace move controller so open tabs and repository references follow moved paths using the same semantic maintenance pipeline as Navigator drag/move.
      \item Changing the active editor tab clears stale Navigator selection, reveals the backing file, centers its row vertically, and keeps the selection blue with white text even while keyboard focus remains in the editor.
   \end{itemize}
