   \section{Bug fix}
   \begin{itemize}
      \item A selected PencilKit stroke group can now be dragged from anywhere inside the lasso selection body, instead of requiring the small move handle.
      \item Selection-body dragging accepts both a direct finger touch and Apple Pencil input.
      \item Only the already selected strokes are translated; non-selected strokes remain unchanged.
      \item Existing proportional resize handles, canvas-boundary clamping, and move undo behavior are preserved.
      \item Outside the selected region, Pencil lasso input continues to pass through to the canvas so a new selection can be drawn normally.
   \end{itemize}
