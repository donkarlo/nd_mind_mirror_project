QShortcut handling in the\n   context controller competed with the QTreeView/FileSystemPanel key handling;\n   Ctrl+V could additionally enter the existing clipboard-image paste path before\n   the internal file clipboard operation was selected.\n\n   \section{Fix}\n   A dedicated NavigatorClipboardKeyEventFilter now owns plain Ctrl+C, Ctrl+X,\n   and Ctrl+V while the Navigator tree has focus.  It invokes the same multi-path\n   controller methods used by the right-click menu.  Ctrl+V is claimed only when\n   the internal file/folder clipboard contains live paths; otherwise the event is\n   deliberately left unconsumed so the existing clipboard-image paste behavior\n   remains unchanged.  The competing Navigator clipboard QShortcut objects are\n   disabled.\n\n   \bibliographystyle{plainnat}\n   \bibliography{/home/donkarlo/Dropbox/repo/nd_shared_research/bibliography/bibliography.bib}\n\end{document}\n
