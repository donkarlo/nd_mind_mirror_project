   \section{Navigator Copy, Cut, and Paste}
   The later workspace interaction layer was replacing the canonical multi-path
   Navigator menu, while additional shortcut controllers introduced duplicate
   ownership of Ctrl+C, Ctrl+X, and Ctrl+V.  The workspace interaction layer now
   preserves the existing \texttt{NavigatorMultiPathContextController} as the
   sole context-menu/clipboard owner, and the redundant shortcut ownership
   controllers are removed from the runtime path.

   \section{Managed graphic deletion}
   Deleting a managed PNG/JPG/JPEG now submits its existing
   \texttt{.ndgraphic} companion in the same background deletion request.  This
   prevents stale orphan sidecars from being left behind when the raster is
   intentionally deleted from the Navigator.

   \section{Rename into an orphan sidecar}
   A stale destination sidecar is replaceable only when its referenced raster
   no longer exists, its image name matches its own stem, and its source owner
   is compatible with the source sidecar.  Replaceability is evaluated before
   the move batch begins, so moving the raster first cannot invalidate the
   orphan-sidecar decision before the sidecar move executes.
