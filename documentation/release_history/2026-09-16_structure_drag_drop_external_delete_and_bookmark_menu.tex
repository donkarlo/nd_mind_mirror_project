      \section{Changes}
      \begin{itemize}
         \item LaTeX Structure now includes tables in addition to headings and images.
         \item Structure rows can be dragged to reorder complete source spans or to change a heading's parent; heading commands inside the moved subtree are shifted consistently.
         \item Autosave no longer recreates a canonical file that was deleted externally while its editor tab remained open.
         \item Navigator explicitly refreshes its filesystem model when an open file disappears externally and after create/delete/rename operations.
         \item The Bookmarks menu has one contextual bookmark action instead of two competing \texttt{Bookmark Selection} actions.
      \end{itemize}

      \section{Architecture}
      Parsing, move planning, tree drag/drop, source application, autosave policy, and filesystem-model refresh remain separate classes. The implementation does not add runtime monkey patches or hot-fix modules.
