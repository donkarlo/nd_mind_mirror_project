   \section{Bug fixes}

   \begin{itemize}
      \item The Preview diagnostics Copy control now occupies the top-right of
      the diagnostics header, while the usage hint is shown on its own line.
      \item The Copy menu contains only the supported diagnostic export formats:
      plain text and YAML. The global Undo/Redo controller no longer injects
      editor history actions into unrelated menus merely because an editor still
      has keyboard focus.
      \item The divider between \texttt{Trace / problem} and
      \texttt{Location / details} is user-resizable. Dragging the header divider
      left or right gives more horizontal space to the desired diagnostics column.
   \end{itemize}
