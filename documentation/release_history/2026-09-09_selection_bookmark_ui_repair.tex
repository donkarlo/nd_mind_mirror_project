   \section{Bookmark Selection}

   Selection bookmarking is now an actual editor capability rather than an
   isolated controller test.  The Bookmarks menu exposes a dedicated
   \textbf{Bookmark Selection} action, Source right-click exposes the same
   action whenever text is selected, and Visual selected text uses the same
   canonical Source-range bookmark path.

   Selection bookmarks persist both source endpoints and readable selected
   text.  Their endpoints relocate together with the bookmarked source line
   when content is inserted or removed above them.  The regular
   \verb|Ctrl+Shift+B| bookmark action also becomes selection-aware whenever an
   explicit selection is active.

   \section{Visual toolbar}

   The special LaTeX insertion toolbar is now Source-only.  It is completely
   hidden while Visual mode is active and returns when Source mode becomes
   active again.

   \section{Architecture}

   Selection-specific behavior is isolated in focused editor, relocation,
   context-menu, and menu controllers.  The existing regular and large LaTeX
   editors are composed through selection-aware subclasses rather than
   duplicating the complete editor implementation.
