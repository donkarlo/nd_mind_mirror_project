      \section*{TikZ edge path Swift type-check fix}

      The curve path sampler in \texttt{TikZEdgePathGeometry.swift} was simplified so Swift Playgrounds does not have to type-check one large Bézier arithmetic expression. Cubic Bézier sampling is now split into small typed helper calculations for weights and coordinates. The distance and midpoint calculations were also decomposed into simpler scalar steps without changing connector geometry or interaction behavior.

      The updated file passes \texttt{swiftc -parse}. A local Swift type-check was additionally run against lightweight CoreGraphics and TikZ model stubs, confirming that the refactored expressions type-check cleanly.
