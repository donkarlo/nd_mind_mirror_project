   \begin{preview}
      \section{Bug}
      Mind Mirror failed during import because
      \texttt{SelectionLargeLatexEditor} declared
      \texttt{SelectionRangeBookmarkEditorMixin} directly even though
      \texttt{LargeLatexEditor} already inherits the public
      \texttt{LatexEditor}, which owns that same bookmark mixin.

      \section{Fix}
      The duplicate bookmark mixin was removed from the large-editor class
      declaration. The large editor keeps only its additional tab-view-state
      and targeted-TikZ-refresh mixins before \texttt{LargeLatexEditor}, leaving
      one consistent cooperative inheritance chain.
   \end{preview}
