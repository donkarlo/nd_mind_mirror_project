\title{Duplicate Tab Dropdown Arrow Fix}
\date{2026-09-20}
\author{Mohammad Rahmani}

\begin{document}
   \maketitle

   \begin{preview}
      \section{Bug}
      The custom tab-list control was a QToolButton with an attached menu and
      also explicitly used ArrowType.DownArrow. Qt therefore rendered both the
      menu-indicator arrow and the explicit arrow inside the same control.

      \section{Fix}
      The explicit arrow type was removed from the owning
      TabOverflowMenuButton. The button now relies only on Qt's menu indicator,
      so each Pinned/Open row has a single dropdown arrow.
   \end{preview}
