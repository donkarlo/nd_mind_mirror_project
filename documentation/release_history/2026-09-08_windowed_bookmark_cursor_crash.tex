   \section{Fixed behavior}

   Persistent selection bookmarks no longer pass canonical full-file character
   offsets into the bounded QTextDocument used by a windowed large LaTeX
   Source editor.

   \begin{itemize}
      \item Normal Source editors continue to use their ordinary document
      position mapping.
      \item Windowed large Source editors resolve bookmark endpoints to local
      window positions.
      \item Bookmarks that are outside the currently materialized Source window
      are not converted to QTextCursor selections until their source region is
      visible.
      \item Every resolved position is checked against the active
      QTextDocument character range before QTextCursor receives it.
      \item Visual bookmark highlights are also range-checked before cursor
      construction.
   \end{itemize}

   This removes the repeated
   \verb|QTextCursor::setPosition: Position ... out of range| calls observed
   immediately before the native process exit code \verb|-11|.
