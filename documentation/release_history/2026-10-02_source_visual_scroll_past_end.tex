      \section*{2026-10-02 --- Source and Visual scroll-past-end}

      Source and Visual editors now provide Word-like breathing room below the
      active caret while typing near the bottom of the viewport.

      \begin{itemize}
         \item A shared caret scroll-margin controller is used by both Source
               and Visual editors.
         \item The QTextDocument root frame receives visual-only bottom space
               proportional to the viewport height.
         \item The focused caret is kept above the lower viewport edge while
               typing, so additional empty working space remains visible below it.
         \item Signal blockers preserve the canonical source and document
               modified state while the visual margin changes.
         \item Resize and font/layout changes recompute the available bottom space.
      \end{itemize}
   \end{preview}
