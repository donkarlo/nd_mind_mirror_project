   \section{Navigator rename refresh}

   Background rename/move completion now triggers an explicit Navigator
   filesystem-model refresh. The QFileSystemModel root watcher/cache is rebound,
   the stored expansion state is restored, and the renamed path is revealed
   again. This prevents the old filename from remaining visible after the file
   was already renamed successfully on disk.

   \section{Preview diagnostic panel}

   The vertical splitter between the last valid PDF and the LaTeX diagnostic
   panel now has a wider, visible horizontal handle with a resize cursor and
   tooltip. The diagnostic header also exposes a copy control that copies the
   complete diagnostic, including raw compiler output and the structured trace,
   as either readable plain text or YAML.

   \section{Bookmark consistency}

   Source and Visual context-menu bookmark actions capture the canonical
   selection before the menu action is invoked, restore that same selection,
   and then call the same \verb|toggle_bookmark_at_cursor| path used by the main
   Bookmarks action. Context-menu bookmarking therefore uses the same stored
   selection/highlight behavior as the top editor/menu action.

   \section{Architecture}

   The changes use focused controllers and serializers:
   \begin{itemize}
      \item \verb|NavigatorFilesystemModelRefreshController| owns Navigator model refreshes.
      \item \verb|SelectionBookmarkContextController| owns captured selection replay.
      \item \verb|LatexDiagnosticSerializer| owns text/YAML diagnostic export.
   \end{itemize}
