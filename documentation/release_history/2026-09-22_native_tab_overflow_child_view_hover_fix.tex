   \begin{preview}
      \section{Bug}
      The previous hover controller assumed the overflow list itself was a
      top-level popup window.  Under the active Qt desktop style, the visible
      list is a child \texttt{QAbstractItemView} inside a separate popup frame,
      so the controller never attached to the real list that retained the blue
      highlight.

      \section{Fix}
      Popup discovery now begins from every nearby top-level popup window and
      locates its child item view.  The controller installs one hover delegate
      on that real viewport.  Each mouse move restores the previously hovered
      row and paints only the current row light purple; leaving the viewport
      clears the transient hover.  Item text and icons are left to the original
      delegate unchanged.
