\section{Bug fix}

Source scrolling no longer computes the complete per-tab view state and visible
source position for every scrollbar value change. A dedicated
\texttt{EditorViewStateCoordinator} now coalesces rapid view activity, captures
the expensive state only after scrolling becomes idle, and flushes state
synchronously at tab-switch boundaries. This removes
\texttt{cursorForPosition()} based view-state work from the Source scroll hot
path while preserving exact tab restoration.
