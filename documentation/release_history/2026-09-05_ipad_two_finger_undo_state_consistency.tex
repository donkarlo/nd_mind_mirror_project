   \section{iPad Undo}
   \begin{itemize}
      \item Changed the app-owned Undo gesture from a two-finger double tap to a two-finger single tap.
      \item Kept the legacy PencilKit native two-finger Undo recognizer disabled so the atomic drawing and raster history remains the single source of truth.
      \item After an app-owned Undo or Redo snapshot is applied, PencilKit's native undo manager is cleared. This prevents stale native stroke actions from restoring strokes that were removed by the application history when the Pencil next touches the canvas.
      \item Same-document Ubuntu graphic updates continue to be treated as save acknowledgements rather than remote replacements, so the current iPad canvas remains authoritative after Undo.
   \end{itemize}
