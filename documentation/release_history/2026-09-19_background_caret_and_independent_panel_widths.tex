\section{Bug fix}
The configured Source and Visual caret now remains visible and continues using
the configured blink interval after keyboard focus moves to another visible
panel or application window.  The configurable caret controller is the single
caret owner; the retired steady non-focus caret renderers are no longer
installed.

The main horizontal layout now keeps Navigator/Structure and Preview widths
stable when the outer application window changes width.  Source/Visual is the
elastic pane that receives the added or removed width.  Explicit splitter-handle
drags remain available for intentional pane resizing.
