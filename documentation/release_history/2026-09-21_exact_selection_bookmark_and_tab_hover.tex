\begin{preview}
\section{Tab hover}
Pinned/Open proxy tabs now track one transient hover index.  The hovered tab is
painted light purple and the index is cleared on mouse leave, so hover can no
longer leave a tab permanently blue.
\section{Selection bookmarks}
Visual bookmark resolution now tries the literal user-selected text before the
Visual structural serializer.  A serializer that returns a complete LaTeX
paragraph or section can therefore no longer widen a bookmark made from only a
few highlighted words.  Structural serialization remains only an exact
fallback for transformed Visual text.  When a short exact selection lies inside
a stale broad bookmark created by an older build, adding the exact bookmark now
replaces that containing broad range so the section-sized highlight disappears.
\end{preview}
