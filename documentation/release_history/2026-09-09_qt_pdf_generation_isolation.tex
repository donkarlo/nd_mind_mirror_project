\title{Qt PDF generation isolation}
\date{2026-09-09}
\author{Mohammad Rahmani}

\begin{document}
   \maketitle

   \begin{preview}
      Fixed a remaining native Qt Quick PDF crash that could terminate Mind
      Mirror with exit code \texttt{-11} during rapid live-preview changes with
      large page-count transitions.

      \begin{itemize}
         \item The PDF currently displayed by \texttt{PdfMultiPageView} is no
         longer reloaded in place.
         \item Every successful render is loaded into a freshly instantiated
         generation viewer while the last known-good generation remains visible.
         \item Promotion happens only after the fresh generation reports a ready
         \texttt{PdfDocument} with pages.
         \item Intermediate successful renders are collapsed to the newest
         generation without mutating the active PDF document.
         \item The previous generation is retained as the inactive slot until a
         later generation needs that slot, at which point the complete QML view
         is destroyed and recreated before loading another PDF.
         \item Native fit-document resources and the preview status timer are
         explicitly released when the Qt widget closes.
      \end{itemize}

      This isolates page/link delegates from document source changes and avoids
      the stale-page condition observed as \texttt{qt.pdf.links: failed to load
      page} immediately before native segmentation faults.
   \end{preview}
