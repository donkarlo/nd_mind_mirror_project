      \section{Large file opening}
      Large LaTeX construction could call the virtualized editor's
      \texttt{toPlainText()} during cooperative mixin initialization before the
      instance field \texttt{\_force\_visible\_plain\_text} existed.  The
      shared public LaTeX editor now provides the bootstrap default, allowing
      large files such as \texttt{evil.tex} to construct normally.

      \section{Overflow hover}
      The overflow list now implements explicit per-row mouseout restoration.
      Every pointer move resolves the row under the pointer with
      \texttt{indexAt}; the previous row is repainted with the normal palette
      background before only the current row receives the light-purple hover
      background. Leaving the viewport clears the hover completely.
   \end{preview}
