   \section{Fixed behavior}

   Source scrolling no longer jumps upward when asynchronously rendered formula
   or table previews change reserved block space above the visible viewport.

   The scroll-anchor correction now uses the scrollbar value that is current at
   the moment of each correction.  Consequently, the immediate correction and
   the deferred correction after Qt geometry recalculation are idempotent: the
   second pass preserves the first pass instead of restoring the stale pre-layout
   scrollbar value.

   A regression test covers both repeated restoration after geometry settles and
   shrinking preview space above the viewport.
