\section{Bug fix}
The Visual editor no longer imports or monkey-patches the retired
\texttt{PersistentCaretOverlay}. Visual caret rendering is now composed directly
with the shared \texttt{CursorAppearanceController}, while Source continues to
use the same controller through the normal editor architecture.

This removes the stale startup dependency that caused
\texttt{ModuleNotFoundError} after the legacy overlay file was removed. The
configured caret color, height, thickness, and blinking behavior now have one
implementation instead of a second runtime-patched caret path.
