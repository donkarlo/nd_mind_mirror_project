\section{Bug fix}

Active editor tabs no longer depend on fixed-delay retries to become highlighted
in Navigator. A dedicated \texttt{NavigatorPathRevealController} now follows
\texttt{QFileSystemModel} loading events, expands ancestor directories
incrementally, and selects the requested file as soon as its model index is
valid. Rapid tab changes replace stale pending targets, and delayed timer-based
selection retries were removed from the strict active-selection controller.
