      \section*{External graphic bridge SIGTERM fix}

      Mind Mirror no longer performs stale graphic-bridge cleanup from the bridge manager constructor. A healthy canonical bridge already listening on port 8766, including a bridge launched by ND Control Panel, is now adopted as an external bridge before any stale-process cleanup is considered.

      Stale cleanup runs only when the canonical endpoint is unreachable and Mind Mirror actually needs to start an iPad bridge. The endpoint is checked again after cleanup to avoid racing a bridge that appeared concurrently. Closing Mind Mirror continues to terminate only a bridge process that Mind Mirror itself created, never an externally owned Control Panel bridge.

      This prevents a healthy \texttt{Mind mirror ipad} process from receiving SIGTERM and being reported by ND Control Panel as \texttt{exit code -15} during ordinary Mind Mirror startup.
   \end{preview}
