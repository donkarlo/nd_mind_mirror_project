   \begin{preview}
      \section{Bug}
      The overflow list stylesheet colored both hover and selected item states.
      The native popup could keep multiple rows in a selected state, causing
      every visible option to receive the purple background.

      \section{Fix}
      Persistent selected rows are now visually transparent. Only the native
      hover state receives the light-purple background. Text color is left
      entirely untouched. QMenu popups still keep exactly the action under the
      pointer active and clear it when the pointer leaves.
   \end{preview}
