      \section*{TikZ label persistence, stable toolbar, live refresh, and render coalescing}

Inline node and connector label editing now commits the current draft before selection is cleared or switched. Pencil Scribble and keyboard edits therefore survive a tap outside the edited element without requiring Enter.

The TikZ property toolbar no longer contains a label field and no longer disappears when the selection is cleared. It keeps the most recently relevant node or connector controls visible. Node and connector property rows use one fixed height, with wide connector controls scrolling horizontally instead of changing the canvas layout.

Connector arrowhead terminology is now \textbf{Filled / Empty}. Empty arrowheads use a closed triangular outline rather than the previous two-sided open chevron, matching the Filled triangle geometry while leaving the interior unfilled.

The shared bridge now coalesces TikZ preview rendering per file. Canonical source saves and Ubuntu update events remain immediate, but rapid drag, resize, and style revisions replace the pending render request instead of starting a separate expensive renderer for every intermediate source revision. Superseded render results are not sent back to the iPad.

Ubuntu's asynchronous TikZ preview cache now records the newest file generation for each target. A slower render from an older mtime/size generation is discarded instead of deleting and replacing a newer cache entry, preventing stale Source/Visual previews that previously appeared correct only after switching views.

The same low-latency TikZ event now resolves the changed workspace path and immediately reloads that file when it is already open in a desktop Source tab. Source text, Source inline graphics, Visual, and PDF Preview therefore refresh from the canonical save without waiting for the slower general external-file scan.

The iPad follow-up build error in the TikZ property toolbar was fixed by supplying both SwiftUI \texttt{fixedSize} arguments explicitly. The raster lasso move handler now checks only that a selection exists instead of binding an unused immutable \texttt{selection}, removing the corresponding Swift compiler warning without changing lasso behavior.
