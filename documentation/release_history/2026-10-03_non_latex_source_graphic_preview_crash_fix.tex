      \section*{2026-10-03 --- Non-LaTeX Source graphic preview crash fix}

      Fixed a Source graphic preview controller crash that occurred when a
      non-LaTeX text editor became the active editor.

      \begin{itemize}
         \item The optimized Source graphic preview controller now verifies
               that the active editor is a \texttt{LatexEditor} before reading
               the LaTeX-only \texttt{edit\_mode} property.
         \item The same type guard is applied to position refresh, layout
               rebuilding, and delayed geometry settling.
         \item Generic text tabs therefore leave the LaTeX Source graphic
               preview controller dormant instead of raising
               \texttt{AttributeError}.
         \item A regression test checks that non-LaTeX editors are rejected
               before Source-mode access.
      \end{itemize}
   \end{preview}
