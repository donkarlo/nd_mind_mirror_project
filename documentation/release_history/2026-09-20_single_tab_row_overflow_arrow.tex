   \begin{preview}
      \section{Bug}
      Each Pinned/Open tab row could display both the explicit Mind Mirror tab
      dropdown and a native QTabBar overflow scroller arrow. The base tab bar
      created the platform scroller before the specialized controller disabled
      scroll buttons, and some Qt styles kept the native control visible.

      \section{Fix}
      The stable tab-row owner now disables native QTabBar scroll buttons and
      suppresses the QTabBar scroller subcontrol at the row style level. The
      explicit Mind Mirror dropdown remains the only arrow at the right side of
      each row.
   \end{preview}
