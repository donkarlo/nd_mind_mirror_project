   \begin{preview}
      \section{Change}
      The custom Pinned/Open tab-list dropdown was removed completely.  The
      control that opened a filename list with checkboxes is no longer created,
      and its dedicated button/scroller support classes were removed.

      \section{Result}
      Pinned and Open rows now use only the canonical QTabBar behavior from
      PinnedTabController.  No custom checkbox file-list menu is attached to
      either row.
