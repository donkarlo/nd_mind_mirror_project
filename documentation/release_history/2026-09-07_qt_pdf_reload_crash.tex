\date{2026-09-07}
\author{Mohammad Rahmani}

   \maketitle

   \section{Fixed behavior}

   Rapid successful LaTeX generations no longer reach the Qt Quick
   \verb|PdfDocument| loader as an unrestricted burst.

   \begin{itemize}
      \item The first generated PDF is still presented immediately.
      \item Subsequent generations arriving inside a short native-PDF loading
      interval are collapsed so that only the newest PDF is handed to Qt.
      \item A newer LaTeX compilation failure cancels any queued successful
      intermediate PDF, preserving the last known-good preview behind the
      structured diagnostic tree.
      \item The change is isolated in an OOP handoff coordinator and does not
      alter LaTeX rendering, source synchronization, zoom, Fit, or diagnostic
      path resolution.
   \end{itemize}

   \section{Observed failure}

   The previous implementation could repeatedly detach and attach the QML
   \verb|PdfDocument| source while typing. Qt Quick PDF logged
   \verb|PdfDocument: Cannot open:| during those detach cycles and could
   terminate the process with native exit code \verb|-11|.
