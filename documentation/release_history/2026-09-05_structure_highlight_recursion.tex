\title{Structure highlight recursion fix}
\date{2026-09-05}
\author{Mohammad Rahmani}

\begin{document}
   \maketitle

   The Structure highlight controller could recurse through a legacy runtime wrapper during startup after Structure highlighting was moved into \texttt{LatexStructurePanel}. The controller now calls the panel class implementation directly instead of dispatching through an instance method that may have been replaced by old runtime code. This keeps one canonical Structure highlight implementation and prevents the startup \texttt{RecursionError}.
