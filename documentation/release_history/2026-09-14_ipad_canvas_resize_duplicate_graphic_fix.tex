      \section*{iPad canvas resize no longer duplicates editable graphic content}

      Fixed a bridge persistence bug in which changing only the logical canvas
      dimensions could commit the paired rendered PNG as a recovered background
      while the old editable PencilKit drawing and image objects were still
      stored in the \texttt{.ndgraphic} document.

      The compatibility bridge now persists an inferred paired-image background
      only when the same save also replaces all editable layer categories that
      were flattened into that recovery image. Metadata-only canvas-size updates
      therefore preserve the existing drawing, image-object identities, and
      background exactly as stored.

      Regression coverage verifies repeated canvas-height changes, preservation
      of editable object IDs and object count, bounded serialized file size, and
      the later safe background migration during a full editable-layer save.
      The iPad canvas-size operation remains metadata-only.

      This bug fix does not modify the drawing interaction model, PencilKit
      coordinate behavior, the canvas resize UI, or any TikZ implementation.
   \end{preview}
