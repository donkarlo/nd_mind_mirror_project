      \section{Bug}
      QMenu's internal selected action could remain visually active while the
      pointer moved to another item. Styling the selected pseudo-state therefore
      allowed more than one stale purple item, and the platform style could
      switch selected text to white.

      \section{Fix}
      The overflow menu no longer uses QMenu's selected state as hover state.
      The controller owns exactly one hovered QAction. A dedicated proxy style
      first removes Qt's selected, mouse-over and focus flags from every item,
      then marks only that owned action as selected with a light-purple
      highlight palette. Both normal and highlighted text palette roles are
      forced to black. Mouseout clears the owned action and repaints the entire
      small popup, restoring every non-hovered item to the native background.
   \end{preview}
