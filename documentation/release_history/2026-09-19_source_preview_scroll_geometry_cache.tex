\section{Bug fix}

Source scrolling around rendered images, formulas, and tables no longer queries
\texttt{QTextDocument} geometry on every scrollbar event. Preview positions are
resolved once after each layout rebuild into document-space pixel coordinates,
indexed by vertical position, and scrolling only subtracts the current scrollbar
offset. Repeated \texttt{raise()} calls for already-visible preview widgets were
also removed.
