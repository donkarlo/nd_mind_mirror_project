   \begin{preview}
      \section{Regression}
      The previous overflow-hover controller watched arbitrary application
      widgets and could attach a custom item delegate to the Double-Shift
      Search result tree. That changed keyboard-selection highlighting in
      Search.

      \section{Fix}
      The controller is now restricted to transient QMenu windows belonging to
      the Pinned/Open tab row. It never imports or touches QAbstractItemView or
      QTreeWidget. Mouse movement records the exact QAction under the pointer;
      Leave and HoverLeave clear that action and repaint the previous action
      rectangle immediately. Search keeps its native keyboard-current-item
      highlight.
   \end{preview}
