   \begin{preview}
      Fixed the raster iPad editor so increasing or decreasing the logical canvas size does not visually duplicate existing handwritten shapes.

      Raster backgrounds now remain in the same top-left logical canvas coordinate system as PencilKit strokes. They are no longer aspect-fitted and recentered when the canvas dimensions change. The same origin-preserving behavior is used by the live canvas, raster composition, raster erasing normalization, and final PNG rendering.

      This also recovers documents whose canvas metadata had already been enlarged while their stored raster background still had the previous dimensions.
   \end{preview}
