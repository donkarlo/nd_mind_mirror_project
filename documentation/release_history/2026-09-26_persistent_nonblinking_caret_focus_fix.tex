\title{Persistent Non-Blinking Caret Outside Editor Focus}
\date{2026-09-26}
\author{Mohammad Rahmani}

\begin{document}
   \maketitle

   \begin{preview}
      \section{Bug}
      The custom Source caret continued blinking after keyboard focus left the
      editor, while Visual mode still used Qt's native caret behavior.  This
      produced inconsistent cursor feedback between Source and Visual views.

      \section{Fix}
      The shared cursor appearance controller now stops its blink timer on
      \texttt{FocusOut}, keeps the caret visible at its current document
      position, and restarts blinking only after the editor regains focus.
      Visual mode now uses the same cursor appearance controller as Source
      mode, and cursor appearance settings are propagated to both views.
   \end{preview}
