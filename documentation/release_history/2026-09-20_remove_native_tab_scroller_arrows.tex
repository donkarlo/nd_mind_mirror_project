   \begin{preview}
      \section{Bug}
      The intended tab-list arrow was accompanied by native QTabBar overflow
      controls.  Earlier attempts changed the visible arrow itself instead of
      removing the extra native controls.

      \section{Fix}
      The explicit tab-list button again uses Qt's themed DownArrow appearance.
      A dedicated NativeTabScrollerSuppressor owns removal of QTabBar's native
      scroll buttons.  It hides only scroll/arrow QToolButtons and leaves normal
      tab close buttons untouched.
   \end{preview}
