   \begin{preview}
      PDF Preview page-boundary geometry is retained for tight standalone and TikZ previews, while passive scrollbar refresh no longer clamps the viewport to the current page. This allows ordinary wheel scrolling to cross page boundaries in complete multi-page documents without snapping back upward.

      Live PDF reload state now records the current page together with page-local horizontal and vertical ratios. Reload restoration returns to the saved page first and then reapplies the page-local position, preventing live recompilation from restoring the same ratio on page one.

      The page-boundary implementation remains isolated in \texttt{SelectablePdfViewBoundary.qml}; the normal Preview view layers multi-page scroll and reload policy on top of that geometry so single-page tight previews and complete documents do not trade correctness against each other.
   \end{preview}
