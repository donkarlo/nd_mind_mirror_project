   \section{Fixed behavior}

   Mind Mirror no longer fails during startup when the historical
   \verb|LargeDocumentPerformanceController| accesses the former
   \verb|SearchWindow._index_thread| member.

   \begin{itemize}
      \item \verb|SearchWindow| now exposes the historical single-thread name as a
      compatibility boundary backed by the current canonical index-thread lifecycle.
      \item Threads assigned through the historical name are tracked, interrupted, and
      cleaned up together with current index workers.
      \item Typing in Double-Shift Search cancels an obsolete background index refresh
      when a valid prior index is already available.
      \item The base file-index worker periodically yields during large repository scans,
      preventing Python indexing work from starving Qt input handling.
      \item Regression checks cover the legacy member contract and typing-priority
      cancellation path.
   \end{itemize}
