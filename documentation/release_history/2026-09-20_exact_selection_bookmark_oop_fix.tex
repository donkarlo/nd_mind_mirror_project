   \section*{Exact selection-only bookmark regression fix}

   Selection bookmarks are now exact by definition in both Source and Visual
   editing. The Visual resolver no longer accepts an approximate structural
   range when selected text cannot be mapped back to canonical source. The
   bookmark highlighter likewise never paints an approximate paragraph as a
   fallback.

   Exact occurrence matching is isolated in
   \texttt{ExactSelectionRangeMatcher} and shared by the resolver and
   highlighter. Regression tests cover both large and small approximate
   paragraph ranges so a short selection cannot silently expand again.
