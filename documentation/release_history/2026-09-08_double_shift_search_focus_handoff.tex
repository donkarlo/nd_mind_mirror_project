   \section{Bug fix}
   Double Shift could open the Search window while keyboard focus still belonged
   to the Source editor. Fast typing immediately after the shortcut could
   therefore modify Source text or lose the first characters of the query.

   The Double-Shift input layer now arms a bounded activation handoff before the
   Search signal is emitted. Keystrokes received during the top-level-window
   focus transition are captured, prevented from reaching the old editor, and
   replayed in original order as soon as the Search line edit receives focus.
   The handoff automatically cancels after 1200 ms if focus is not transferred.
