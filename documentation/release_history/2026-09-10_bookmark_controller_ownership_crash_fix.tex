   \section{Crash fix}

   The Source-special LaTeX toolbar no longer creates a second
   \verb|BookmarkSelectionMenuController| with the toolbar object passed in
   place of the bookmark \verb|QAction|.  Bookmark menu ownership remains in
   \verb|EnhancedMainWindow|, where the controller receives the canonical
   \verb|_toggle_bookmark_action|.

   This removes the startup \verb|AttributeError| on
   \verb|SpecialLatexToolbar.triggered| and prevents duplicate event-filter and
   signal ownership.  Selection bookmarking in the Bookmarks menu and the
   Source/Visual context menus continues to use the existing canonical
   selection-bookmark controllers.
