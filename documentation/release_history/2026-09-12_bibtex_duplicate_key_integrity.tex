      \section{BibTeX duplicate-key integrity}
      Mind Mirror now protects \texttt{.bib} files against duplicate BibTeX entry keys. Plain-text paste is rejected before insertion when the resulting bibliography would contain a duplicate key, including duplicates contained entirely inside the pasted text. Replacing a selected existing entry with a new entry using the same key remains valid when the final document contains only one occurrence.

      Existing duplicate keys are also detected when a \texttt{.bib} file is opened or edited. The error dialog reports each duplicated key together with the source line numbers where it occurs. The rule is scoped only to \texttt{.bib} files and leaves all other generic text editors unchanged.
   \end{preview}
