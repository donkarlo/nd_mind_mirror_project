   \begin{preview}
      \section{Bug}
      Moving the pointer over a visible Pinned/Open proxy tab could leave that
      tab painted with the native selected blue state after the pointer left.

      \section{Fix}
      Pure mouse movement is now owned entirely by the hover presenter and is
      not delegated to QTabBar. Native current-on-drag behavior is explicitly
      disabled. While a tab is hovered, native selected/focus painting is
      suppressed and the tab receives only the requested light-purple
      background. Leaving the row clears the transient hover index so the tab
      immediately returns to its normal prior state.
   \end{preview}
