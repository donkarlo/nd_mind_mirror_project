      \section*{Bug fix}

      Preview diagnostics no longer interpret ordinary TeX package-loading
      paths as warnings merely because the path contains the word
      \verb|package| or \verb|packages|.

      \begin{itemize}
         \item The compiler diagnostic extractor now delegates severity
         decisions to the existing \verb|LatexDiagnosticSeverityClassifier|.
         \item Warning-only output therefore starts with an actual warning, so
         the existing diagnostic-node normalization keeps it at warning
         severity instead of presenting a false compilation error.
         \item Additional BibTeX syntax failures, including repeated entries,
         are classified as hard errors so they cannot be hidden behind citation
         warnings.
         \item The shared \verb|seehere.tex| helper no longer reapplies the
         load-time \verb|colorlinks| option through \verb|\hypersetup| after
         \verb|hyperref| has already been loaded.
         \item Regression tests cover package-loading lines and BibTeX repeated
         entries.
      \end{itemize}
   \end{preview}
