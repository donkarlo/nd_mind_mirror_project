      \section*{Bug fix}
      Live Preview no longer treats a warning-only BibTeX or Biber subprocess
      exit as a fatal compilation failure.

      \begin{itemize}
         \item Added an OOP bibliography subprocess result classifier.
         \item Warning-only bibliography exits continue to the normal second
         LaTeX pass, allowing the PDF preview to remain available.
         \item Real bibliography errors, including missing database/style files
         and explicit error/fatal output, still stop compilation.
         \item Added focused tests for BibTeX warnings, Biber warnings, hard
         bibliography errors, and non-bibliography phases.
      \end{itemize}
   \end{preview}
