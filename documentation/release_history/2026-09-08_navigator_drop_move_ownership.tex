      \section{Navigator drag-and-drop move ownership}
      \begin{itemize}
         \item Fixed Navigator drag-and-drop so a custom filesystem move is consumed by Mind Mirror instead of also authorizing Qt's native \texttt{QFileSystemModel} move.
         \item Prevented the same selected files or folders from being moved twice, which previously caused the background worker to report \texttt{Source does not exist} after Qt had already relocated the source paths.
         \item Added a regression test that verifies a handled custom drop returns \texttt{IgnoreAction} to Qt and never accepts the proposed native move action.
      \end{itemize}
