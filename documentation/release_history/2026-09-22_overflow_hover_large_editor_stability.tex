   \begin{preview}
      \section{Overflow hover}
      Repeated Show events could wrap the same popup item delegate again. Each
      nested delegate retained an older hovered row, which made purple
      backgrounds accumulate. Popup configuration is now idempotent: one view
      owns exactly one hover delegate, the previous row is repainted on every
      mouseout, and only the current row receives the purple background.

      \section{Large files}
      The large LaTeX editor now enters the existing bounded Source-window mode
      at 120000 characters instead of materializing multi-hundred-kilobyte
      documents in one QTextEdit. This applies directly to files such as
      \texttt{evil.tex}.

      \section{Editor lifetime}
      The caret controller now stops queued work as soon as its editor is
      destroyed, preventing event-filter access to deleted Qt objects.
   \end{preview}
