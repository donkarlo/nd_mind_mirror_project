      \section{Bug fix}
      Hidden editor projections no longer perform presentation work for the active
      mode. Source cursor movement does not synchronize the hidden Visual cursor,
      Visual cursor movement does not synchronize the hidden Source cursor, and
      Visual edits update the canonical Source incrementally while Source syntax
      highlighting, logical line-number updates, and bookmark relocation are
      suspended. These Source-only services resume only after an explicit switch
      back to Source.

      Source formula, table, image, and TikZ preview controllers now gate their
      timers and polling by the active Source mode. An in-flight Source formula
      LuaLaTeX process is cooperatively cancelled when Source becomes hidden.
      TikZ bridge updates refresh
      only the currently visible Source or Visual projection. Closing the PDF
      Preview also prevents structural-input validation, dependency polling, and
      processing of late renderer dependency signals.

      Formula/table and image overlays now wait for Qt to settle QTextBlock margin
      changes and scroll-anchor restoration before caching document-space geometry.
      This prevents valid rendered formulas from receiving reserved white space
      while their overlay widget is positioned from stale geometry.

      The previous startup performance hook that replaced Source/Visual methods at
      runtime was removed from this path. Mode isolation and preview behavior are
      now owned by explicit editor/controller classes rather than a runtime
      replacement of those methods.
   \end{preview}
