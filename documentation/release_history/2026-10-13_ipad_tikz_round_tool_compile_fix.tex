      \section*{Fix}
      \begin{itemize}
         \item Removed the obsolete circle tool comparison from
               \texttt{TikZCanvasView.swift}. The single rounded shape tool
               now renders a live ellipse preview, which becomes circular
               when its drag rectangle is square.
         \item Fixed the Swift compile error where the removed enum case
               \texttt{TikZCanvasTool.circle} was interpreted as
               \texttt{ButtonBorderShape.circle}.
         \item Added a regression assertion to ensure the obsolete
               canvas tool reference cannot reappear.
         \item Raised the iPad app version to 0.31.60 (build 87).
      \end{itemize}
   \end{preview}
